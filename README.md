# vagminv.me

Personal portfolio website for Vagmin Viswanathan.

🔗 **Live Site**: [vagminv.me](https://vagminv.me)

## About

Portfolio showcasing my work as an aspiring software engineer and student studying Computer Science and Physics at Dartmouth College.

## Tech Stack

- **Framework**: React 19 with TypeScript
- **Build Tool**: Vite
- **Styling**: SCSS + Tailwind CSS
- **Icons**: Lucide React
- **Code Quality**: ESLint + TypeScript

## Deployment

Site is automatically deployed to GitHub Pages via GitHub Actions.

## Project Structure

```
vagminv.me/
├── src/
│   ├── components/     # React components
│   ├── data/          # Content and data
│   ├── styles/        # SCSS stylesheets
│   ├── types/         # TypeScript type definitions
│   └── context/       # React context providers
├── public/            # Static assets
└── dist/             # Production build (generated)
```

## Features

- Dark mode support with system preference detection
- Responsive design
- TypeScript for type safety
- SCSS-based styling architecture
- Optimized production builds
